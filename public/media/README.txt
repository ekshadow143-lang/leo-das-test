TEAM LEO DAS — MEDIA FOLDER
Drop your files in THIS folder (public/media), commit, push to GitHub. Vercel redeploys and the site uses them.
Use lowercase names. Any extension works: mp3 wav m4a mp4 webm png jpg jpeg webp svg.
Videos: keep under ~25 MB each (GitHub blocks files over 100 MB).
